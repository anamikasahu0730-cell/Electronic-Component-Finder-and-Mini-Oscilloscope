# Electronic Component Finder & Mini Oscilloscope

## Project Overview
An interactive Python-based desktop application that bridges the gap between electronics theory and practical visualization. It combines an Electronic Component Finder with a Mini Oscilloscope, allowing users to explore essential electronic components, generate different signal waveforms, and analyze their characteristics through a user-friendly graphical interface.

## Features

### 1. Electronic Component Finder
- Explore essential electronic components.
- View component images and basic information.
- Learn about Resistors, Capacitors, Diodes, LEDs, and Transistors.

### 2. Mini Oscilloscope
- Generate and visualize different waveforms.
- Supports Sine, Cosine, Square, and Triangle waves.
- Adjust signal amplitude and frequency.
- Analyze waveform characteristics.

### 3. Signal Analysis
- Amplitude
- Frequency
- Time Period
- RMS Value

### 4. User Interface
- Interactive graphical user interface.
- Dark and Light themes.
- Simple and user-friendly controls.

## Technologies Used
- **Python** – Core programming language.
- **Tkinter** – Graphical User Interface.
- **NumPy** – Numerical calculations and signal generation.
- **Matplotlib** – Waveform visualization.
- **Pillow (PIL)** – Image handling.
